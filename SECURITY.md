# Security Policy

Security fixes are supported for the latest release. Please do not open a
public issue for a vulnerability. Use GitHub's private vulnerability reporting
for `cyperx84/herdr-notes`; if unavailable, contact the repository owner through
the address on their GitHub profile.

Include affected versions, reproduction steps, and impact. Expect an initial
response within seven days. Note files are local plaintext Markdown and are not
encrypted by this project.
